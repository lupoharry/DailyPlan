# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-05

### Added

- Initial release of Daylight - Daily Journal with Mood Tracker
- Dashboard with entry count, writing streak, average and most common mood statistics
- Latest seven days view with entry indicators
- Recent entries list on dashboard
- Journal creation and editing for any past, present, or future date
- One entry per calendar day constraint with proper date handling
- Ten selectable moods with emoji indicators
- Optional guided reflections for journal entries
- Character count display for journal content
- Advanced search functionality across journal entries
- Combined filtering by date range, month, mood, and sort options
- Interactive calendar view with entry and mood indicators
- Direct links from calendar dates into journal entries
- Entry detail view with full content and metadata
- Edit and delete functionality with confirmation dialogs
- Empty states for various views
- JSON export of all journal data
- Validated JSON import with date conflict handling
- Local Storage persistence with no backend required
- Responsive layouts for desktop, tablet, and mobile devices
- Keyboard focus support and accessible navigation
- Safe HTML sanitization for user-entered text
- Browser compatibility across modern browsers
- Smooth animations and transitions
- Google Fonts integration (DM Sans and Manrope)
- System font fallbacks for offline usage

### Technical

- Pure HTML5, CSS3, and ES6+ JavaScript
- Modular JavaScript architecture with separate concerns
- No dependencies beyond browser APIs and Google Fonts
- Optimized Local Storage usage
- Efficient DOM manipulation and rendering
- Cross-browser testing and validation
